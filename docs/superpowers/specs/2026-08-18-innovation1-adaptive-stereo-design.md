# 创新点一：目标精度与视觉状态双驱动的时空自适应双目测量

## 边界

本模块接收已校正的左右灰度帧、已知相机模型和点的历史状态，输出每点的视觉测量 `XYZ_mm`、视差、质量证据和置信度状态。它不实施多点结构动力学一致性、轨迹校正或故障归因；这些属于后续创新点。

## 处理闭环

1. `gradient_quality` 输出梯度均值/标准差、Laplacian 方差、纹理/模糊/总质量分数，均归一化为 0–1。
2. `optical_flow` 执行前向和后向 LK，只有通过 FB 误差门限才提供预测点。
3. `motion_predictor` 维护每点像素、视差、XYZ、速度和置信度历史，支持 `constant_velocity` 与 `kalman`。
4. `adaptive_search` 从目标深度精度、纹理、FB 误差、预测残差和上一帧置信度得到每帧局部搜索半径。
5. `stereo_matcher` 在预测视差附近的校正极线上执行 ZNCC 加梯度代价；低置信度时回退到 SGBM。
6. `subpixel_refiner` 对相邻三点代价做受限抛物线精化，拒绝平坦、边界或不稳定曲线。
7. `confidence` 融合图像质量、匹配成本、左右一致性、FB 误差、时间残差和邻域残差，控制 HIGH/MEDIUM/LOW 行为。

## 控制策略

- HIGH：接受局部测量并更新状态。
- MEDIUM：扩大由 `adaptive_search` 计算的窗口并再匹配。
- LOW：执行 SGBM fallback；失败则输出时间预测，达到连续失败阈值后请求重新初始化。

## 精度规划

以 `Z=fB/d` 和 `sigma_Z≈Z²/(fB)*sigma_d` 计算所需视差标准差；在候选基线中选取满足目标深度误差的最小基线，若均不满足则返回误差最小的最大可用基线并标记不可达。

## 仿真实验

针对基线 60/100/140/180/220/260/300 mm，距离 1000–5000 mm，视差噪声 0.02/0.05/0.1/0.2 px，重建并输出 `baseline-distance-error.csv` 与 `baseline_distance_rmse.png`。CSV 保留基线、距离、噪声、理论深度标准差和 Monte Carlo RMSE（mm）。

## 验收

- 所有质量、置信度输出为有限的 0–1 值。
- LK 必须经 FB 验证；局部搜索半径随输入证据及目标精度改变。
- 亚像素模块不输出 NaN/Inf。
- 低置信度行为可观测为“扩窗 → fallback → 预测/重初始化”。
- 精度扫描覆盖 7×5×4 组合并输出 CSV 和图。
