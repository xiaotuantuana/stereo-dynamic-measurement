# 创新点三：跨层残差指纹驱动的双目测量故障归因与策略化自恢复

## 边界

创新点三只解释故障类型并选择、验证恢复策略。输入中的 `C_phy`、`r_phy` 和校正轨迹直接来自创新点二；本层禁止重算 PSD、相位、相干性或多点动力学。

## 数据契约

`FaultFingerprint` 统一保留图像质量、模糊、左右/极线/匹配/邻域残差、光流/FB/时间残差、参考公共运动、几何健康和 `physics_residual=1-C_phy`。每个字段必须是有限值或显式 unavailable 状态，不能以异常吞掉。

## 诊断与恢复闭环

1. 参考监测器通过特征点、FB-LK 与 RANSAC 估计固定背景公共运动。
2. 几何健康器从参考点对应的垂直视差中位数、P95 和 RMS 输出健康分数。
3. 规则引擎输出十类故障及各条件证据；随机森林仅为可选比较器。
4. 恢复管理器选择差异化策略，例如局部重匹配、扩大搜索、重检特征、公共运动补偿、外参更新请求或全局初始化。
5. 验证器要求恢复后 `C_phy` 增加且主要残差下降，否则升级策略或标为不可用。

## 故障基准

注入 stereo mismatch、occlusion、blur、flow drift、camera motion、extrinsic drift 和 tracking loss；clean 与每个故障各 20 个随机种子。数据、配置、日志、指标和摘要保存在时间戳输出目录。

## 验收

- 干净仿真无 NaN/Inf，默认三维 RMSE 不高于 1 mm。
- 注入样本产生故障类型、分数、恢复动作和恢复成功字段。
- 大多数可恢复故障满足恢复后 RMSE 降低；基准导出 accuracy/precision/recall/F1、恢复率、前后 RMSE 和误报率。
- 视频、相机、ROI、分辨率、标定和读取失败均有显式验证与日志。
